BioSTEMedia — Mobile responsive version (fixed images)

Files:
- index.html: responsive BioSTEMedia page.
- assets/: local images and infographics, including the gallery images extracted from the supplied full MHTML page.

How to preview:
1. Extract the ZIP completely.
2. Open index.html in a modern browser.

How to publish on GitHub Pages:
1. Upload index.html and the entire assets folder together into the same bioSTEMedia_mobile folder in your GitHub repository.
2. Keep the folder and filenames unchanged; index.html references images in assets/.
3. Commit the changes and wait for GitHub Pages to redeploy.
4. Refresh the published page with Ctrl+F5 (or clear the mobile browser cache).

Google Sites embed:
Use a Full page embed and point it to the published GitHub Pages URL, for example:
https://aqlihytawasila-png.github.io/bio/bioSTEMedia_mobile/
