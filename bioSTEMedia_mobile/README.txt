BioSTEMedia — Mobile responsive version

Files:
- index.html: responsive page rebuilt from the uploaded Google Sites HTML.
- assets/: images extracted from the supplied *_files.zip archive.

How to preview locally:
1. Extract this ZIP file completely.
2. Open index.html in a modern browser.

How to use as a Google Sites Full page embed:
1. Host the contents of this folder on a static website host (for example GitHub Pages or Netlify). Keep the assets folder next to index.html.
2. Open the published HTTPS URL and check it on a phone.
3. In Google Sites, choose Pages > + > Full page embed, then enter the published page URL.

Notes:
- The page uses local image files for the photos, table images, and infographic assets supplied in the ZIP.
- The three carousel groups that were background images in the original Google Sites export still load their images from the original public Google Sites image URLs. Those need an internet connection.
- Table/infographic images are responsive and can be tapped to enlarge.
- This is a redesigned responsive reading layout; some native Google Sites navigation chrome and the embedded task preview were replaced by simpler mobile-friendly elements. The task link points to the Drive file found in the supplied HTML.
